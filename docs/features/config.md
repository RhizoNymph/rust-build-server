# config — layered configuration

## Scope
Load and validate rbs configuration; expose escape hatches. Non-scope: kache
configuration (generated by `setup`), secrets (never in config; MinIO creds
live in `~/.config/rbs/minio.env` and are only read by `setup`).

## Sources (lowest → highest)
1. Built-in defaults.
2. `~/.config/rbs/config.toml` (`$XDG_CONFIG_HOME` respected).
3. Nearest `.rbs.toml` walking up from cwd (project-local overrides).
4. Environment: `RBS_MODE`, `RBS_LOCAL`, `RBS_REMOTE_HOST`, `RBS_PRIORITY`, `RBS_LOG`, `RBS_CONFIG`.

## Schema
```toml
[remote]
host = "node0"                 # ssh destination
enabled = true
max_rtt_ms = 40                # above this, skip remote (slow WAN links)
connect_timeout_ms = 3000
mirror_root = ""               # "" = same absolute path; else prefix replacement
remote_bin = ".local/bin/rbs"  # rbs binary on the remote (non-interactive ssh PATH lacks ~/.local/bin)

[local_server]
enabled = true
socket = "~/.local/state/rbs/server.sock"
autostart = true

[policy]
mode = "auto"                  # auto | remote | local | plain
local_subcommands = ["run"]    # always run locally (escape hatch by subcommand)
post_build = "pull_and_link"   # pull_and_link | none
env_allowlist = ["CARGO_*", "RUST*", "CC", "CXX", "PKG_CONFIG_*", "SQLX_OFFLINE", "DATABASE_URL"]
priority = "agent"             # interactive | agent | background

[server]                       # used by `rbs server`; laptop and node0 differ
tokens = 0                     # 0 = nproc - reserve_cores
reserve_cores = 2
max_jobs = 8
min_mem_available_gib = 8
job_mem_max_gib = 24
queue_limit = 32
job_timeout_secs = 3600

[store]                        # shared kache S3 store GC (rbs store-gc; timer on node0)
max_size_gib = 40              # size cap; 0 = GC disabled
low_watermark_percent = 90     # evict down to this fraction of the cap
min_age_hours = 24             # never evict objects newer than this
touch = true                   # after successful compiling builds, fire `rbs store-touch`
touch_after_hours = 24         # touch throttle window; objects fresher than this are not rewritten

[sync]
rsync_path = "rsync"
extra_excludes = []
```

## Files
- `crates/rbs-config/src/lib.rs` — `Config`, `load(cwd) -> Result<Config, ConfigError>`, `Mode`.
- `crates/rbs-config/src/layers.rs` — discovery/merge of the sources above.
- `crates/rbs-config/src/env.rs` — env overrides + allowlist glob matching (`CARGO_*`).

## Invariants
- `RBS_LOCAL=1` ≡ `RBS_MODE=local`. `RBS_MODE` beats every file.
- Paths are expanded (`~`) at load; `Config` holds absolute paths only.
- Unknown keys are errors (`deny_unknown_fields`) — typos must not silently disable features.
- `ConfigError` is `thiserror`; callers never see raw `toml::de::Error`.
